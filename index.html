Personal Drive Backup

A backup you control.

A personal file backup workflow built with rclone and restic. It transfers selected files and backup data between an owner-managed computer or cloud environment and the owner’s Google Drive.

Purpose & access

Built for personal backups.

01 / PURPOSE

Store and recover files

The workflow uploads backups, lists their metadata, downloads selected files and restores saved versions. Ordinary file transfers and restic repositories are handled separately.

02 / PERMISSION

Google Drive access

Google authorization lets rclone read and manage Drive files for backup and restore. The Drive scope can allow access across the authorized account; actual operations use the owner’s configured folders and commands.

03 / CONTROL

Owner-operated

This utility is maintained for personal use by Dacheng Shu (ShuDacheng). Operations run in the owner-managed environment, and access can be revoked through Google Account settings.

Data handling

Understand what is stored.

Restic encrypts the contents of its backup repository. Files transferred directly with rclone rely on the protection of the chosen storage and any encryption separately configured by the owner.

OAuth credentials stay in private configuration in the owner-managed environment. This public website provides application information and policies; it has no Google sign-in form.
